# Alcance — COV App

## Problema y público

COV App ayuda a estudiantes y pequeños equipos a registrar y dar seguimiento a sus tareas desde Android y Web. El problema que resuelve es la pérdida de visibilidad sobre pendientes personales en herramientas dispersas.

## Propuesta de valor

Organiza, prioriza y completa tus tareas desde una única aplicación sincronizada con tu cuenta.

## MVP entregable

- Registro e inicio de sesión con correo/contraseña y Google.
- Crear, editar, completar, filtrar y eliminar tareas.
- Descripción y prioridad por tarea.
- Perfil del usuario y cierre seguro de sesión.
- Persistencia en Cloud Firestore y actualización en tiempo real.
- Aplicación Android y Web con identidad visual azul de COV App.

## Fuera de alcance

- Colaboración entre usuarios, notificaciones push, adjuntos y calendario.
- Versión de Windows (opcional según el plan académico).
